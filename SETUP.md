# Mukesh — Instrument Serif GitHub Profile

This package is designed for the public profile repository:

`Programmer-MukeshKrishnaaNK/Programmer-MukeshKrishnaaNK`

## What changed

- Black / white / grayscale editorial design.
- Instrument Serif is bundled locally and used for the large display typography.
- GIF assets are used for the visible animation so the motion is obvious in GitHub's README renderer.
- The project section includes only the public projects you listed.
- GitHub stats and the contribution grid are regenerated by GitHub Actions.

GitHub supports GIFs in profile READMEs, and the profile README is shown when a public repository matches your username and contains `README.md`.

## Install

1. Replace your profile repository's `README.md` with this package's `README.md`.
2. Upload the `assets/`, `scripts/`, and `.github/` folders.
3. Keep `assets/fonts/InstrumentSerif-Regular.ttf` and `InstrumentSerif-Italic.ttf`.
4. Commit to the default branch.
5. Open **Actions → Update Profile Graphics → Run workflow** once.

The workflow also runs automatically once per day.

## Local preview

Requires Python + Pillow:

```bash
pip install pillow
python scripts/generate_profile.py
```

## Animation note

The README intentionally uses `.gif` assets rather than relying on JavaScript. GitHub sanitizes README HTML and does not provide a normal way to run custom JavaScript inside the README, while GIF images render as animated media.

## Customization

- Edit the text in `README.md`.
- Edit the project names in `scripts/projects.py` and `scripts/generate_profile.py`.
- Change `USERNAME` in the workflow only if the repository belongs to another account.
- If GitHub caches an old GIF, bump `?v=2` to `?v=3` in `README.md`.
